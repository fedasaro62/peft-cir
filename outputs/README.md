# Experiment outputs

Everything here is regenerated by the jobs and is gitignored. The layout is what
`tools/plot_*.py` expect:

```
outputs/
  <BENCHMARK>/<arch>_peft[_faithful][_lit]/    one dir per trained cell, plus benchmarks.csv
    <method>_<target>[_<loss>]/
      best.pt        the trainable tensors only
      meta.json      everything needed to rebuild the model, and the score that selected it
  cross/<arch>_peft[_<loss>]/                  cross-dataset transfer rows
  figures/                                     tools/plot_cross_results.py's PNGs
```

`<BENCHMARK>` is `CIRR`, `fashioniq`, `shoes` or `CIRCO`.
